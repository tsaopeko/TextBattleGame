# TextBattleGame

一款使用 C# 與 Windows Forms 開發的文字戰鬥 RPG 遊戲，透過回合制戰鬥、角色成長、技能與道具系統，體驗簡單的冒險玩法。

## 📖 專案介紹

TextBattleGame 是一個以 C# WinForms 製作的個人練習專案。

本專案著重於物件導向程式設計、遊戲系統架構、回合制戰鬥邏輯，以及 Windows Forms 使用者介面的實作。

## ✨ 目前功能

- **角色系統**
  - 角色名稱與等級
  - HP、MP 與角色屬性
  - 升級與自由分配屬性點數
  - 經驗值累積與角色成長

- **回合制戰鬥**
  - 普通攻擊與暴擊機制
  - 魔法技能攻擊
  - 怪物反擊
  - 戰鬥勝利、逃跑與死亡處理

- **技能系統**
  - 技能解鎖與等級限制
  - MP 消耗
  - 不同技能的傷害倍率

- **道具與背包系統**
  - 生命藥水與魔力藥水
  - 戰鬥中使用道具
  - 背包物品管理

- **關卡與怪物系統**
  - 關卡推進
  - 怪物資料管理
  - 特定關卡的首領設定

- **存檔與讀檔**
  - 多個存檔欄位
  - 儲存角色、關卡與背包資料
  - 從存檔繼續遊戲

## 🛠️ 開發環境

- **語言：** C#
- **框架：** .NET 10.0
- **UI：** Windows Forms (WinForms)
- **開發工具：** Visual Studio 2026
- **版本控制：** Git / GitHub

## 🚀 如何執行

1. 下載或 Clone 本專案。
2. 使用 Visual Studio 2026 開啟 `TextBattleGame.sln`。
3. 等待 Visual Studio 完成專案載入。
4. 確認已安裝 .NET 10.0 SDK。
5. 建置專案。
6. 執行程式。

## 📁 專案架構

專案依照不同職責拆分為多個類別與表單，主要包含：

- `Forms`：遊戲畫面、開始畫面、角色資訊及存檔介面。
- `Player`：玩家角色資料與屬性。
- `BattleManager`：回合制戰鬥邏輯。
- `ExperienceSystem`：經驗值、升級與死亡懲罰。
- `SkillSystem`：技能管理與解鎖。
- `InventorySystem`：背包與道具管理。
- `EnemyGenerator`：怪物產生與關卡首領設定。
- `SaveLoadSystem`：遊戲存檔與讀檔。

實際檔案位置與類別配置請以專案目前的原始碼為準。
